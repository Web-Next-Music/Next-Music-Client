## Internal API for the Yandex Music `window.nextmusicApi`.

The idea and implementation of the APIs for controlling the Yandex Music player and addon integration were adapted from [PulseSync Mod](https://github.com/PulseSync-LLC/PulseSync-mod/) to provide compatibility with themes and addons originally developed for [PulseSync](https://pulsesync.dev/).
